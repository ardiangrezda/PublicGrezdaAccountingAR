# Grezda Accounting System (Demo Version)

A demo version of the Grezda Accounting System built with Blazor Server and .NET 8.

## 🚀 Features

### Available Modules
- **Sales Management** - Welcome page
- **Purchase Management** - Welcome page
- **Subjects** - Buyer/Supplier management
- **Articles** - Product catalog
- **Administration** - User and system management

## 🛠️ Technical Stack

- **Framework**: .NET 8.0
- **UI Framework**: Blazor Server
- **Database**: SQL Server / SQLite
- **Authentication**: ASP.NET Core Identity
